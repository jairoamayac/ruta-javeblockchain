Guía de preinstalación

Todos

  • Freighter, extensión del navegador: freighter.app
  • Cuenta de GitHub
  • Git
  • VS Code o Cursor
  • Node 20 o superior

Builders además

  • Rust con rustup (1.84 o superior)
  • rustup target add wasm32v1-none
  • stellar-cli: brew install stellar-cli o el script oficial
  • En Windows: WSL2 con Ubuntu

Verificación: stellar --version y cargo --version.

Para todos

Documentación base

  • Stellar Docs → Learn → Fundamentals: cuentas, activos, operaciones, transacciones, fees y consenso. Lectura obligatoria de las sesiones 1 y 2.
  • Stellar Lab: construir, firmar y enviar transacciones a mano en testnet y leer el XDR.
  • stellar.expert (testnet): explorador para verificar hashes, balances y contratos.
  • Freighter: wallet del navegador.
  • Friendbot: desde Stellar Lab o en https://friendbot.stellar.org?addr=G… para fondear cuentas de testnet.
Builders

Contratos Soroban

  • Getting Started: setup, Hello World y despliegue en testnet. Es la ruta exacta de la sesión 2.
  • Soroban Examples: contratos de referencia (token, auth, events, cross-contract, timelock).
  • Storage y Authorization: lo que se pregunta en la prueba oral.
  • Scaffold Stellar y bindings TypeScript: frontend conectado al contrato (sesión 3).
  • Rust Book, capítulos 1 a 6 y 10: lo mínimo para leer un contrato. Quien no sabe Rust lo lee en la semana 1.
Fundamentos

Producto y wallet

  • Stellar SDK de JavaScript y Freighter API: construir y firmar pagos desde una web app (sesión 3).
  • Anclas y SEPs: cómo entra y sale dinero real. Lectura conceptual.
  • Stellar Quest: retos para practicar entre sesiones.
  • Curso virtual de BAF sobre Stellar: material complementario.
